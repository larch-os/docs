# Plans

Per-feature plan files — one markdown per task/feature.

## Naming

`YYYY-MM-DD-short-feature-name.md` or `feature-name.md` — keep it descriptive and kebab-case.

## Template

```markdown
# Feature: <name>

## Context
Why this work is needed, links to issues/discussions.

## Scope
What is in / out of scope.

## Approach
Technical approach, key files to touch.

## Tasks
- [ ] task 1
- [ ] task 2

## Validation
How to verify (e.g. `bun run build`, `bun run types:check`).

## Notes
Open questions, dependencies.
```
