---
title: Booting the live session
description: What happens when you boot the ISO, and what to do with it
---

Boot the ISO and it takes you straight into a working desktop. There's no rescue TTY to click through first.

## What boots

- SDDM autologs into a dedicated `larch` user (uid 1000) with passwordless `wheel` sudo.
- The session is niri (Wayland compositor) with noctalia as the shell.
- Display resolution auto-detects. The config doesn't hardcode an output or connector name, so it works on whatever monitor you plug in.
- Network comes up through NetworkManager, reachable from noctalia's network panel.
- The default terminal is kitty, the default browser is Firefox.

## Why boot into a full desktop instead of a minimal shell

So you can actually use the hardware before committing to an install: test Wi-Fi, check GPU acceleration, try trackpad gestures, confirm your keyboard layout, all inside the real environment Larch ships.

## Starting the installer

<Callout type="warn">
  The installer doesn't exist yet (see [Roadmap](/docs/development/roadmap)). The design calls for launching it from a tray icon or a terminal command, running fullscreen inside the live session. Once it's built, this section documents the actual launch flow instead of the plan for it.
</Callout>

## Live session limitations worth knowing

- The `larch` user has no password across reboots. If you need SSH into a live session, run `passwd` first.
- The session is stateless. Nothing you change persists past a reboot, this isn't your installed system yet.
