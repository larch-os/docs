The variant these docs describe everywhere else. niri as the compositor, noctalia as the shell, stock Arch repos underneath. See the [Software guide](/docs/software-guide) for the full breakdown.

## Software

- [niri](/docs/software-guide/niri), scrollable-tiling Wayland compositor
- [noctalia](/docs/software-guide/noctalia), the panel and shell
- [kitty](/docs/software-guide/shell-and-terminal) as the terminal, zsh + oh-my-zsh as the shell
