## Boot it in a VM

The fastest way to try Larch right now is in a VM. Boot the ISO and you're straight into a working desktop, no rescue TTY to click through first: SDDM autologs into a `larch` user, niri (Wayland compositor) with noctalia as the shell, dark theme, kitty as the terminal, Firefox as the browser. Display resolution auto-detects rather than assuming real hardware, so it works the same in a VM's virtual output as on a laptop screen.

One requirement: niri needs a real GPU render node. A default VM setup (plain `virtio-vga`, no 3D) shows a black screen forever. See [Testing in a VM](/docs/development/testing-in-a-vm) for the exact libvirt/QEMU config that works.

Two things worth knowing about the live session itself, VM or real hardware:

- The `larch` user has no password across reboots. Run `passwd` first if you need SSH into it.
- The session is stateless. Nothing you change persists past a reboot, this isn't an installed system yet.
