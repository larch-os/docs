## htop and btop

[htop](https://htop.dev/) and [btop](https://github.com/aristocratos/btop) are both interactive process viewers. btop adds resource graphs (CPU, memory, disk, network) and a fancier UI; htop is the lighter, older standby.

## lazygit

[lazygit](https://github.com/jesseduffield/lazygit) is a terminal UI for git: stage hunks, rebase, browse the log, without memorizing flags.

## paru

[paru](https://github.com/Morganamilo/paru) is an AUR helper, a pacman wrapper that also builds and installs AUR packages.

## uv

[uv](https://docs.astral.sh/uv/) is a Python package and project manager: dependency resolution, virtualenvs, and Python version management in one fast tool.

## k3d and kubectl

[k3d](https://k3d.io/) runs [k3s](https://k3s.io/) (lightweight Kubernetes) inside Docker, for spinning up a local cluster without a VM. [kubectl](https://kubernetes.io/docs/reference/kubectl/) is the standard Kubernetes CLI, for talking to that cluster or any other.

## herdr

[herdr](https://github.com/herdrdev/herdr) is a terminal runtime for coding agents like Claude Code, Codex, and Cursor, keeping sessions persistent and reattachable.
