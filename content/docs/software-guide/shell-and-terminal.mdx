## kitty

[kitty](https://github.com/kovidgoyal/kitty) is the default terminal.

## zsh + oh-my-zsh

The default shell is [zsh](https://www.zsh.org/), running [oh-my-zsh](https://github.com/ohmyzsh/ohmyzsh) with the robbyrussell theme, plus [zsh-autosuggestions](https://github.com/zsh-users/zsh-autosuggestions), [zsh-syntax-highlighting](https://github.com/zsh-users/zsh-syntax-highlighting), and [fzf-tab](https://github.com/Aloxaf/fzf-tab).

Alongside that: [eza](https://github.com/eza-community/eza), [fzf](https://github.com/junegunn/fzf), and [zoxide](https://github.com/ajeetdsouza/zoxide).
