---
title: Default apps
description: Software the installer adds automatically, no selection needed
---

These install during setup regardless of what you pick on the optional extras screen.

## chezmoi

[chezmoi](https://www.chezmoi.io/) manages dotfiles across machines from a single source repo.

## pass

[pass](https://www.passwordstore.org/) stores passwords as GPG-encrypted files, managed through git.

## Pika Backup

[Pika Backup](https://apps.gnome.org/en/PikaBackup/) is a GNOME backup app built on Borg, for encrypted, scheduled backups.
